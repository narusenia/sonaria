# ハモリ要件定義

方式は ADR-0006。ARA では DAW でトラックを複製し、複製側でハモリを作る。非 ARA では WAV で書き出して DAW に貼る。

## REQ-HARM-001: 度数シフト

| 項目 | 内容 |
|------|------|
| ID | REQ-HARM-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

選択したノートを、プロジェクトのキーとスケールに沿って n 度（±1〜±7、オクターブ）上下へ移す。
スケール外の音のノートは、近いスケール音を基準にずらし、警告色で示す。

### 受入条件

- [ ] C メジャーで E → 3 度上が G、F → 3 度上が A になる
- [ ] 移したあとも、ノート内のピッチの動き（しゃくり・ビブラート）が保たれる
- [ ] 1 操作が undo 1 回で戻る

### 依存要件

- REQ-WF-001

## REQ-HARM-002: 他トラックのゴースト表示

| 項目 | 内容 |
|------|------|
| ID | REQ-HARM-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ARA で、同じドキュメント内の他トラックのノートを半透明でピアノロールに重ねる。表示するトラックを選べる。編集はできない。非 ARA では使えない。

### 受入条件

- [ ] 主旋律トラックのノートが、ハモリトラックの編集画面に時間をそろえて表示される
- [ ] 主旋律を編集すると、ゴーストにも反映される
- [ ] Cubase と Studio One で動作を確認している

### 依存要件

- REQ-INFRA-004

## REQ-HARM-003: 主旋律へのタイミング揃え

| 項目 | 内容 |
|------|------|
| ID | REQ-HARM-003 |
| 優先度 | Should |
| ステータス | Draft |

### 説明

ゴースト表示している主旋律に、選択したノートの開始位置と終了位置を揃える（VocAlign 相当）。強さ 0〜100% を持つ。
対応するノートは、時間の重なりで自動で決める。

### 受入条件

- [ ] 強さ 100% で、対応するノートの開始・終了が主旋律と一致する（隣のノートやリージョンの端とぶつかる所を除く）
- [ ] 子音・ブレスは既存の伸縮処理に従い、録音どおりの長さを保つ
- [ ] 1 操作が undo 1 回で戻る

### 依存要件

- REQ-HARM-002
