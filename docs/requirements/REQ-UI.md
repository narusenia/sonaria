# UI 要件定義

## REQ-UI-001: JUCE UI の継続と LookAndFeel の刷新

| 項目 | 内容 |
|------|------|
| ID | REQ-UI-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

既存の JUCE UI を少しずつ改良する。全面的な作り直しと WebView は採用しない（ADR-0005）。
見た目は LookAndFeel とデザイン値（色・余白・フォント）の集約で刷新する。

### 受入条件

- [ ] 色・余白・フォントの値が 1 か所にまとまっている
- [ ] ピアノロールの描画がネイティブのまま

### 依存要件

- なし

## REQ-UI-002: 操作応答

| 項目 | 内容 |
|------|------|
| ID | REQ-UI-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ノート数が多い曲でも、編集操作に遅れなく反応する。ゴースト表示を加えても同じ。

### 受入条件

- [ ] 基準曲（3 分・約 600 ノート・ゴースト 1 トラック）で、スクロール・ズーム・ドラッグが 60fps を保つ（Apple Silicon）
- [ ] Quantize / Straighten のスライダー操作が、描画に 1 フレーム以内で反映される

### 依存要件

- なし
