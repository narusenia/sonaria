# 作業速度要件定義

目的: ざっと補正 → ずれ探し → 修正 → 試聴の各段階を速くする。仕様は `docs/specifications/editing.md`。

## REQ-WF-001: スケールの自動適用

| 項目 | 内容 |
|------|------|
| ID | REQ-WF-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

解析が終わったら、既存の `detectMajorOrRelativeMinor` で検出したキーを自動で適用し、ツールバーに表示する。
ユーザーが変更したキーは、再解析しても上書きしない。

### 受入条件

- [ ] 解析後、操作なしでキーとスケールがツールバーに表示される
- [ ] 手で変えたキーは再解析で変わらない
- [ ] 検出したキーを 1 操作で元に戻せる（undo）

### 依存要件

- なし

## REQ-WF-002: Quantize / Straighten

| 項目 | 内容 |
|------|------|
| ID | REQ-WF-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

選択したノートに、強さ 0〜100% の Quantize と Straighten をかける（VariAudio 方式）。
Straighten はビブラートを残すモードを持つ。スライダーを動かしている間は試聴に反映し、離したら 1 回の undo 単位にする。

### 受入条件

- [ ] Quantize 100% でノートの平均ピッチがスケール上の音に一致する
- [ ] Straighten 100% でノート内の揺れが平らになり、ビブラート保持モードではビブラートが残る
- [ ] スライダー操作 1 回が undo 1 回で戻る

### 依存要件

- REQ-WF-001

## REQ-WF-003: ずれの色分け表示

| 項目 | 内容 |
|------|------|
| ID | REQ-WF-003 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ノートを、スケール上の音からのずれ（セント）で色分けする（Vovious 方式）。しきい値は設定で変えられる。

### 受入条件

- [ ] ずれが小・中・大の 3 段階で色が変わる
- [ ] 編集するとすぐに色が更新される
- [ ] 色だけに頼らず、ずれの値をノートのツールチップで読める

### 依存要件

- REQ-WF-001

## REQ-WF-004: ずれたノートへのジャンプ

| 項目 | 内容 |
|------|------|
| ID | REQ-WF-004 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

キー 1 つで、しきい値を超えてずれている次（前）のノートを選択し、画面をそこへ移す。

### 受入条件

- [ ] ジャンプでノートが選択され、表示範囲に入る
- [ ] 最後のノートの次は最初のノートに戻る
- [ ] ずれたノートがないときはその旨を表示する

### 依存要件

- REQ-WF-003

## REQ-WF-005: キーボードだけの編集

| 項目 | 内容 |
|------|------|
| ID | REQ-WF-005 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ノートの選択・移動・ツール切り替え・Quantize / Straighten を、マウスなしで行える。割り当ては `editing.md`。

### 受入条件

- [ ] 割り当て表のすべての操作がキーボードだけでできる
- [ ] ARA で DAW のショートカットと衝突しないことを Cubase と Studio One で確認している
- [ ] 割り当てをアプリ内で一覧できる

### 依存要件

- REQ-WF-002, REQ-WF-004

## REQ-WF-008: スマート分割

| 項目 | 内容 |
|------|------|
| ID | REQ-WF-008 |
| 優先度 | Should |
| ステータス | Draft |

### 説明

選択したノートを、ピッチが切り替わる位置で分割するツール。感度スライダーで分割位置をプレビューしてから確定する。
解析時の自動分割は行わない（ADR-0008）。

### 受入条件

- [ ] こぶし・メリスマを含むノートが、音程ごとに分割される
- [ ] 確定前に分割位置がプレビューされる
- [ ] 確定が undo 1 回で戻る

### 依存要件

- なし
