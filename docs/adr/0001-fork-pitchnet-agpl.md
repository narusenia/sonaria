# ADR-0001: PitchNet をハードフォークし、AGPL-3.0 の個人 OSS とする

- 状態: 採用
- 日付: 2026-11-15

## 背景

元にする PitchNet と HachiTune はどちらも AGPL-3.0 である。PitchNet は HachiTune の派生で、ブレス・歯擦音検出、Sibilant Balance、r8brain による変換、ポリフォニック編集が加わっており、更新も活発（約 8.3 万行）。
Sonaria は UI と合成部分を大きく変えるため、本家を定期的にマージするとコンフリクトが増え続ける。

## 決定

- PitchNet をハードフォークする。本家の更新は必要なものだけ手で取り込む
- 個人プロジェクトとして AGPL-3.0 で公開する。PitchNet・HachiTune の帰属表示を残す
- 独立して使える機能（Spectral エンジン、スマート分割など）は、本家にも PR を送れる形で作る

## 結果

- クローズドな商用製品にはできない
- 本家のバグ修正は自動では入らない。取り込むときは README に取り込み元のコミットを記録する
- 同梱する ONNX モデルのライセンスは別途確認が要る（REQ-INFRA-003）
