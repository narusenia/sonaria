# ADR-0003: ハイブリッドエンジンは区間ごとの選択とし、出力のブレンドはしない

- 状態: 採用
- 日付: 2026-11-15

## 背景

PitchNet には AI（PC-NSF-HiFiGAN）と Classic（PSOLA）のエンジンがあり、プロジェクト単位で切り替える。PSOLA は `DspSynthesisRequest` を受け取り、エンジンを差し替えられる形になっている。
混ぜ方の候補は 3 つあった: ノート単位の選択、自動ルーティング、出力の同時ブレンド。

## 決定

- ノート単位の選択を先に作り（M3）、その上に自動ルーティングを足す（M5）
- 出力の同時ブレンドはしない。位相がそろわずコムフィルタ状の音になりやすいため
- 境界はクロスフェードでつなぐ

## 結果

- エンジンが同じフレームを鳴らすのはクロスフェード中だけになる
- ノートに `engine` を持たせるため、プロジェクト形式が変わる（旧形式は読めるようにする）
