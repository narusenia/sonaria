# ADR-0005: UI は既存の JUCE を改良し、WebView や全面作り直しはしない

- 状態: 採用
- 日付: 2026-11-15

## 背景

既存の UI は JUCE で約 2.9 万行ある。HachiTune は GUI を全面的に作り直している。
Sonaria の目的は操作性の向上で、作業速度の多くは見た目ではなく操作（ショートカット・一括操作・ジャンプ）で決まる。ピアノロールは描画量が多い。

## 決定

- 既存の JUCE UI を少しずつ改良する
- 見た目は LookAndFeel とデザイン値の集約で刷新する
- WebView と全面作り直しはしない

## 結果

- 機能追加を止めずに UI を良くできる
- Web 技術での素早い見た目の調整はできない
