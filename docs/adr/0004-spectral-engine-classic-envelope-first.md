# ADR-0004: Spectral エンジンの包絡推定は古典的な手法から始める

- 状態: 採用
- 日付: 2026-11-15

## 背景

Vovious は FFT による解析と、ニューラルネットによるフォルマント追従を組み合わせて自然な補正をしている（紹介記事による。詳細は非公開）。
同じ方向のエンジンを作りたいが、ニューラル推定器にはデータセット・学習・ONNX 化が必要で、個人の OSS には重い。また、PSOLA でも十分自然なら作る価値が薄い。

## 決定

- 包絡推定は True Envelope などの古典的な手法で作り、推定器を差し替えられる形にする
- M4 の目標は「PSOLA より自然な場面があるか」の確認とする。なければ Spectral を既定の選択肢から外す

## 結果

- 早く音を出して比べられる
- ニューラル推定器は M4 の結果を見て判断する（backlog）
