# ADR-0006: ハモリはトラックを複製して度数シフトで作る

- 状態: 採用
- 日付: 2026-11-15

## 背景

ハモリの出し方の候補は、WAV 書き出し、プラグインの追加出力バス、プラグイン内のボイス混合だった。追加出力バスは DAW ごとに設定が違い、ARA との組み合わせも複雑になる。

## 決定

- ARA では、DAW でトラックを複製し、複製したトラックで度数シフトしてハモリを作る
- 非 ARA では、度数シフトした結果を WAV で書き出して DAW に貼る
- 音程はキーとスケールに沿った度数指定で決め、手で直したノートは個別に上書きする
- ARA では他トラックのノートをゴースト表示し（M2）、その上で主旋律にタイミングを揃える機能（VocAlign 相当、M5）を作る

## 結果

- ハモリの EQ やミックスは DAW 側で自由にできる
- ゴースト表示とタイミング揃えは ARA でだけ使える
