# 編集操作

関連: REQ-WF-001〜008、REQ-HARM-001〜003

## ずれ

- ノートのずれ = ノートの有声フレームの平均ピッチ（セント）− スケール上で最も近い音（セント）
- 色分けのしきい値（既定）: 10 セント未満 = 通常、10〜30 = 注意、30 以上 = 要修正
- ジャンプの対象: 要修正（設定で注意も含められる）

## Quantize / Straighten

| 操作 | 計算 | 既存の部品 |
|---|---|---|
| Quantize（強さ s） | ノートのピッチを `s × (最も近いスケール音 − 平均ピッチ)` だけ動かす | Pitch Center マクロ |
| Straighten（強さ s） | ノートの vibrato と drift の factor に `1 − s` をかける | `PitchToolOperations` の factor 操作 |
| Straighten（ビブラート保持） | delta の 2Hz 以下（ドリフト）だけに factor をかける | `PitchToolOperations::scalePitchDrift` |

- Pitch Center ダイアログのスライダーで、選択中のノートに 0〜100% でかける。ドラッグ中は描画と試聴に反映し、OK で undo 1 回分のアクションにまとめる
- 平均ピッチとスケールは、ピッチ欄の Chromatic / Scale（スナップの設定）にかかわらず、プロジェクトのキーのスケールで測る
- ノートの冒頭と末尾 30ms（しゃくり・フォール）には Straighten をかけない（仮）

## キーボード割り当て（仮）

M1 で実装した。Cubase と Studio One のショートカットとの衝突は未確認。一覧は編集メニューの「キーボードショートカット」で出る。

| キー | 操作 |
|---|---|
| ← / → | 前 / 次のノートを選択 |
| Shift + ← / → | 選択を広げる |
| ↑ / ↓ | 選択ノートをスケール上の 1 音上 / 下へ（セントのずれは捨て、スケール音に乗せる） |
| Shift + ↑ / ↓ | 選択ノートを 1 オクターブ上 / 下へ |
| Alt + ↑ / ↓ | 選択ノートを 1 セント単位で上 / 下へ（Shift で 10 セント） |
| N / Shift + N | 次 / 前のずれたノートへジャンプ |
| Q / W | Quantize / Straighten（ビブラート保持）を 100% でかける |
| 1〜4 | ツール切り替え（選択 / 分割 / 描画 / タイミング） |
| Space 長押し中の A | 選択ノートを原音で試聴（M5） |
| H | 度数シフトのダイアログ（M2） |

## 度数シフト（M2）

- 入力: 度数 n（±1〜±7、±8 = オクターブ）、キー・スケール（プロジェクトの値）
- ノートの音 p がスケール上の i 番目なら、移動先はスケール上の i + (n − 1)（n < 0 のときは i + (n + 1)）番目
- p がスケール外なら、下側のスケール音を基準に移し、ノートを警告色にする
- ノート内の delta（しゃくり・ビブラート）は変えず、ノートの基準ピッチだけを動かす

## ゴースト表示（M2）

- ARA ドキュメント内の他の Audio Modification のノートを、DAW のタイムライン位置にそろえて描く
- 上流（PitchNet）のトラック一覧のピン留めで実装済み。左パネルのトラック一覧で、行ごとのピンを押したトラックを表示する。既定はどれもピンなし
- 描画は非アクティブなリージョンと同じ淡いノートに、トラックの色の枠を付けたもの。ヒットテストの対象にしない
- 参照方法: `PitchNetAudioProcessor::getAraProjectForPreview` が、同じ modification の兄弟リージョンは編集中の Project から、他の modification は保存済みの Project から読む。編集のたびに revision が上がり、エディタ側のキャッシュ（`regionPreviewCache`）が作り直される
- 度数シフトでスケール外の音から動かしたノートは、スケール外のまま残るので、ずれの色分けで警告色になる

## タイミング揃え（M5）

- 対応付け: 選択ノートごとに、主旋律のノートのうち時間の重なりが最大のものを選ぶ。重なりがなければ揃えない
- 開始・終了を、`強さ × (主旋律 − 自分)` だけ動かす。伸縮は既存のタイミング処理（子音・ブレスは録音どおりの長さ）を使う

## スマート分割（M5）

- 対象: 選択したノート
- 分割点の候補: ピッチが ±50 セント以上変わり、かつ前後がそれぞれ 60ms 以上安定している位置（仮）
- 感度スライダーで、セントのしきい値と安定時間を一緒に変える
- 確定前は分割位置を縦線でプレビューし、確定で `NoteSplitter` の分割を一括で行う（undo 1 回）
