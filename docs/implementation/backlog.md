# Backlog

予定の決まっていない項目だけを置く。着手したらマイルストーンへ移す。200 行程度まで。

## 機能候補

- 繰り返しフレーズの一括編集（1 番サビの修正を、ピッチの形が似た箇所に適用）
- ピッチの動きのテンプレート（しゃくり・フォール・ビブラートをドラッグで付ける）
- ピッチの動きのコピー＆ペースト（ノート間）
- ビブラートエディタ（ノートごとの深さ・速さ）
- タイミング揃えの拡張（音量の形・語尾の処理も主旋律に揃える）
- ハモリ用の humanize（フォルマントの微調整・タイミングの揺らぎ）
- MIDI リファレンスの読み込み（Vovious 相当）
- コマンドパレット（Cmd+K）
- スケール検出の拡張（メジャー / マイナー以外のスケール）

## 条件付き

- ニューラル包絡推定器: M4 で Spectral が採用され、古典的な推定で不足があるとき（ADR-0004）
- 包絡推定用モデルの学習: 既存モデルが流用できないとき

## 公開前に決める

- Sonaria の商標確認（ADR-0002）
- 配布形態（GitHub Releases のみか、署名・公証付きのインストーラか）
